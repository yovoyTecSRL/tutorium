# Orbix Security Suite - Documentation

## Overview

The Orbix Security Suite consists of two powerful forensic and security analysis tools designed for comprehensive system auditing and incident response.

### Scripts Included

1. **`orbix_audit.sh`** - Comprehensive Security Audit Tool
2. **`orbix_analysis.sh`** - Forensic Package Analysis Tool

## 1. Orbix Audit Script (`orbix_audit.sh`)

### Purpose
Performs comprehensive, non-destructive security auditing of Linux systems, collecting evidence and generating forensic packages for analysis.

### Features
- **Non-destructive**: Read-only operations, preserves system state
- **Comprehensive**: Covers users, processes, services, network, files, logs
- **Structured output**: Organized forensic package with categorized evidence
- **Security scanning**: Integrates with rkhunter, chkrootkit, ClamAV
- **Webshell detection**: Scans for malicious web content
- **Binary analysis**: Examines suspicious executables

### Usage

```bash
# Basic audit (recommended)
./orbix_audit.sh

# Quick mode (skip long scans)
./orbix_audit.sh --quick

# Install missing security tools automatically
./orbix_audit.sh --install-tools

# Get help
./orbix_audit.sh --help
```

### Output Structure

The script creates a timestamped directory `/tmp/orbix-sentinel-YYYYMMDD-HHMMSS/` containing:

```
orbix-sentinel-20240101-120000/
├── logs/                      # System information and logs
│   ├── user_info.txt         # User and authentication info
│   ├── system_info.txt       # Kernel, uptime, hardware
│   ├── network_info.txt      # Network configuration
│   ├── processes_*.txt       # Process information
│   ├── auth_recent.log       # Authentication logs
│   ├── nginx_*_recent.log    # Web server logs
│   └── ...
├── scans/                     # Security scan results
│   ├── suid_files.txt        # SUID/SGID files
│   ├── web_suspicious_patterns.txt  # Webshell patterns
│   ├── rkhunter.log          # Rootkit scan results
│   ├── chkrootkit.log        # Additional rootkit scan
│   └── clamav_*.log          # Antivirus scan results
├── analysis/                  # Analysis workspace
├── evidence/                  # Collected evidence
│   ├── bin_hashes.sha256     # Binary file hashes
│   ├── package_inventory.txt  # Installed packages
│   └── binary_analysis/      # Suspicious binary analysis
└── reports/                   # Generated reports
    ├── summary.txt           # Executive summary
    └── critical_findings.txt # Critical security findings
```

### Integration Points

The audit script integrates with:
- **Systemd services**: Analyzes running services and failed units
- **Docker/Podman**: Containers and images analysis
- **Web servers**: Nginx/Apache log analysis
- **Databases**: Service status checking
- **Security tools**: rkhunter, chkrootkit, ClamAV integration

## 2. Orbix Analysis Script (`orbix_analysis.sh`)

### Purpose
Processes forensic packages generated by `orbix_audit.sh` and creates structured security reports with prioritized findings.

### Features
- **Automated analysis**: Processes audit packages automatically
- **Pattern recognition**: Identifies security threats and indicators
- **Prioritized findings**: P0 (Critical), P1 (High), P2 (Medium)
- **Multiple output formats**: Markdown, JSON, plain text
- **Actionable tickets**: Ready-to-use incident response tasks
- **IP geolocation**: Analyzes suspicious network activity

### Usage

```bash
# Auto-detect latest package
./orbix_analysis.sh

# Analyze specific package
./orbix_analysis.sh --package /tmp/orbix-sentinel-20240101-120000.tar.gz

# Get help
./orbix_analysis.sh --help
```

### Output Files

Creates `/tmp/orbix-analysis-YYYYMMDD-HHMMSS/` containing:

#### Core Reports
- **`summary.md`** - Executive summary with compromise assessment
- **`findings.json`** - Machine-readable structured findings
- **`critical_findings.txt`** - Critical security issues list
- **`issues.md`** - Prioritized tickets for incident response

#### Analysis Data
- **`suspicious_patterns.txt`** - All detected suspicious patterns
- **`suspicious_counts.txt`** - Files ranked by suspicion level
- **`top_ips.txt`** - Most active IPs from logs
- **`ip_geolocation.txt`** - Geographic analysis of IPs
- **`clamscan.txt`** - Antivirus scan results

#### Evidence
- **`suspect_files/`** - Directory containing suspicious files
- **`suspect_files.sha256`** - Cryptographic hashes
- **`bin_strings/`** - String analysis of suspicious binaries

### Findings Priority System

- **P0 (Critical)**: Immediate action required
  - Active webshells
  - Malware detected
  - Root compromise indicators
  
- **P1 (High)**: Resolve within 24 hours
  - Suspicious network activity
  - Configuration vulnerabilities
  - Unauthorized access attempts

- **P2 (Medium)**: Resolve within 72 hours
  - System hardening opportunities
  - Outdated software
  - Security best practices

## Workflow Integration

### 1. Initial Assessment
```bash
# Run comprehensive audit
./orbix_audit.sh

# Quick analysis of results
./orbix_analysis.sh

# Review summary
cat /tmp/orbix-analysis-*/summary.md
```

### 2. Incident Response
```bash
# Emergency audit with analysis
./orbix_audit.sh --quick && ./orbix_analysis.sh

# Check for critical findings
grep -i "P0" /tmp/orbix-analysis-*/issues.md

# Preserve evidence
tar -czf incident-evidence-$(date +%Y%m%d).tar.gz /tmp/orbix-*
```

### 3. Continuous Monitoring
```bash
# Daily security audit (via cron)
0 2 * * * /path/to/orbix_audit.sh --quick && /path/to/orbix_analysis.sh
```

## Security Considerations

### Data Handling
- **Sensitive Information**: Scripts redact private keys and passwords
- **Evidence Preservation**: Maintains chain of custody for forensic evidence
- **No External Communication**: All analysis performed locally

### Permissions Required
- **Read access**: All system files and logs
- **Write access**: `/tmp` directory for output
- **Execution**: Standard Linux utilities and optional security tools

### Tool Dependencies

#### Required (always available)
- `bash`, `find`, `grep`, `awk`, `ps`, `ss`, `tar`
- `systemctl`, `journalctl` (systemd systems)
- `python3` (for JSON generation)

#### Optional (enhanced capabilities)
- `rkhunter` - Rootkit detection
- `chkrootkit` - Additional rootkit scanning  
- `clamscan` - Antivirus scanning
- `debsums` - Package integrity verification
- `whois` - IP geolocation


## Troubleshooting

### Common Issues

1. **Permission Denied**
   ```bash
   sudo ./orbix_audit.sh
   ```

2. **Missing Tools**
   ```bash
   ./orbix_audit.sh --install-tools
   ```

3. **Large Output Files**
   ```bash
   ./orbix_audit.sh --quick
   ```

4. **Analysis Package Not Found**
   ```bash
   ./orbix_analysis.sh --package /path/to/specific/package.tar.gz
   ```

### Performance Considerations

- **Full audit**: 5-15 minutes depending on system size
- **Quick mode**: 2-5 minutes (skips antivirus scans)
- **Analysis**: 30 seconds - 2 minutes per package
- **Disk usage**: 50-500MB per audit package
